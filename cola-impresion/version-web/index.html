i Esta es una demostración estática: los archivos que elijas no se suben a ningún lado y la cola se borra al recargar la página.

El programa real es una aplicación fullstack que GitHub Pages no puede alojar, porque necesita un servidor:

  • Backend (FastAPI, Python): recibe los archivos, los guarda en la carpeta files/ y mantiene la cola en queue.json. Expone los endpoints POST /uploadfile (encolar), POST /getfiles (consultar) y POST /printfile (desencolar).
  • Frontend (React + Vite): esta misma interfaz, pero cada acción llama a la API y muestra el progreso real de la subida.
  • Como la cola vive en el servidor, es persistente y todas las computadoras que abren la aplicación ven la misma cola.

Aquí la API se sustituye por una cola en memoria dentro del navegador que imita sus respuestas. Solo se usan el nombre y el tamaño del archivo; su contenido nunca se lee. Para correr el programa completo, sigue las instrucciones del código fuente en GitHub.

Cola de impresión

Los archivos se imprimen en el orden en que llegan: entran por el final y salen por el frente.
